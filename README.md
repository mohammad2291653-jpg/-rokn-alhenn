# ركن الحناء | Rokn Alhenna

متجر عربي باتجاه RTL لمنتجات العناية بالشعر، مبني باستخدام Next.js App Router وTypeScript وPostgreSQL وPrisma. طريقة الدفع المعتمدة هي **الدفع عند الاستلام**؛ تسجيل الطلب لا يعني تحصيل قيمته. لا يقدم المتجر خدمات نقش الحناء على اليدين.

هذا مستودع تطبيق مستقل يمكن تشغيله على استضافة تجارية وربطه بدومين خاص، دون حساب ChatGPT أو Codex للزبائن.

## الحالة التجارية المهمة

استُلم الشعار الأصلي في ملف ZIP وحُفظ كما ورد. بناءً على طلب المالك، أُعدّت نسخة شفافة منظّفة من الأصل لرأس المتجر وتذييله دون إعادة رسم الحروف. استُلمت دفعة من 26 صورة عبر PDF، ورُبطت 24 صورة بسبعة منتجات مسودة بعد مطابقة الملصقات وتأكيد المالك للمشاط الأحمر. اعتُمدت مدة ماسك السدر ساعة إلى ساعتين، والغسل لخلطة الحناء المتكاملة بماء فاتر ثم شامبو أو ماسك خالٍ من الأملاح بعد 2–6 ساعات، مع حفظ النصوص المطبوعة المختلفة في سجل المراجعة. تبقى صور منتجي المشاط الأخضر مطلوبة. لذلك تُنشأ المنتجات التسعة كمسودات، وتبقى عملية الطلب معطلة إلى أن يرفع المالك الصور الصحيحة ويراجع المحتوى والأسعار والسياسات ويعتمد التفعيل. لا توجد صور عبوات مولدة أو مراجعات أو شهادات جودة مختلقة.

رسوم الضفة الغربية 20 ₪، والداخل الفلسطيني 30 ₪ للطلب كله. قطاع غزة غير متاح. القدس حالة منفصلة بلا سعر معتمد؛ لا يمكن إنهاء طلب لها بسعر نهائي حتى اعتماد الإدارة.

لا تعني قابلية تشغيل التطبيق أنه حصل على اعتماد إطلاق تجاري. راجع [قائمة الإطلاق](LAUNCH_CHECKLIST.md) و[نتائج الاختبارات](TEST_REPORT.md) لمعرفة ما نُفذ فعليًا وما بقي.

## آخر تحديث للتجهيز

طلب المالك تجهيز **الخطة المجانية على Render**. أصبح [render.yaml](render.yaml) مخصصًا لمعاينة خاصة للقراءة فقط، مع PostgreSQL مجاني مستقل، وتعطيل الطلبات ورفع الصور والفهرسة من الخادم. يظل المقترح المدفوع السابق في [render.production.example.yaml](render.production.example.yaml) للمراجعة فقط. حدود النوم بعد الخمول وانتهاء قاعدة البيانات بعد 30 يومًا موثقة في [RENDER_FREE_PREVIEW.md](RENDER_FREE_PREVIEW.md). لم تُنشأ الموارد بعد؛ اختيار مساحة Render ينتظر تأكيد المالك. لا يوجد رابط معاينة مستضاف مؤكد حتى الآن.

نجحت أحدث مجموعة محلية **155/155**: 138 اختبارًا وحدويًا و17 تكاملًا مع PostgreSQL، ثم **10/10** اختبارات للمعاينة الخاصة عبر المتصفحات الخمسة. تشمل منع الطلبات رغم تفعيل إعداد checkout في قاعدة اختبار منفصلة، ومنع صلاحيات الإدارة والتسريب دون جلسة قراءة. نتائج البناء والنشر الأحدث تُسجّل في [TEST_REPORT.md](TEST_REPORT.md) عند اكتمالها. الجولات التالية أدناه تاريخ سابق مستقل.

رُفع المشروع إلى [مستودع GitHub العام المعتمد](https://github.com/mohammad2291653-jpg/-rokn-alhenn)، على الفرع `main`. تضمّن الإصدار [3d4490d](https://github.com/mohammad2291653-jpg/-rokn-alhenn/commit/3d4490d87017809e0bed7d604363df5fa01b56f9) الملفات الـ287، بما فيها الصور الأصلية وPDF المصدر، وتحققت مطابقة بصمات Git وأنماط الملفات مع النسخة المحلية. ملفات الأسرار وقاعدة التطوير مستبعدة. نجحت [أول جولة فحوص GitHub](https://github.com/mohammad2291653-jpg/-rokn-alhenn/actions/runs/40833604777) كاملة: 108 اختبارات وحدوية وتكامل و90 اختبار متصفح، مع TypeScript وESLint والبناء الإنتاجي وتدقيق الاعتمادات. الأدلة في `artifacts/github-ci-verification.json`. رابط المستودع يتيح تصفح المصدر من الهاتف؛ المتجر لم يُنشر إلى استضافة سحابية بعد.

أُضيفت معاينة محمية في `/admin/store-preview` وتفاصيلها في `/admin/store-preview/[slug]`، تعرض بيانات قاعدة البيانات وصور المنتجات مع البحث والتصفية والترتيب وتكبير الصور، دون شراء أو تعديل السلة أو نشر المسودات. يلزم تسجيل دخول المدير قبل الوصول إليها.

نجحت المجموعة المحلية الأحدث **108/108**: 95 اختبارًا وحدويًا و13 تكاملًا مع PostgreSQL، ونجحت تجربة نسخ واستعادة مستقلة **16/16** مع تطابق محتوى 20 جدولًا. أُعدّ `render.yaml` ونجح فحصه مقابل المخطط الرسمي، لكنه لم يُطبّق ولم تُنشأ خدمات مدفوعة أو معاينة خارجية. فحص `npm run preflight:preview -- --json` الحالي يبقى محجوبًا بسبب إعدادات HTTPS وS3 والمدير غير المكتملة. توجد نتائج نهائية ناجحة لـ90 سيناريو متصفح بعد الإصلاح والإعادات، وبناء وتشغيل Docker محلي ناجح؛ التفاصيل وحدود التحقق في [TEST_REPORT.md](TEST_REPORT.md). لقطات المتجر بالمنتجات التسعة: [الجوال](artifacts/owner-store-preview-390.png) و[الكمبيوتر](artifacts/owner-store-preview-1440.png).

## البدء

راجع [إعداد بيئة التطوير](SETUP.md)، ثم [دليل الإدارة بالعربية](ADMIN_GUIDE.md). أوامر العمل الرئيسية:

```sh
npm ci
npm run db:generate
npm run db:migrate
npm run db:seed
npm run admin:create
npm run dev
```

يجب إعداد `.env` وقاعدة PostgreSQL أولًا كما هو موضح في SETUP. لا يوجد مدير افتراضي ولا كلمة مرور تجريبية صالحة للإنتاج.

## بنية المشروع

- `src/app`: واجهات المتجر والإدارة وواجهات HTTP.
- `src/lib`: قاعدة البيانات والمصادقة والتحقق والحسابات على الخادم.
- `prisma/schema.prisma`, `prisma/migrations`, `prisma/seed.ts`: المخطط والترحيلات وبيانات البداية.
- `tests`: الاختبارات الآلية.
- `templates/products.csv`, `templates/prices.csv`: قوالب لمراجعة ونقل بيانات المنتجات والأسعار بعد التحقق؛ لا تُنشر البيانات بالاعتماد على الملف وحده، ولا تعني وجود زر استيراد CSV آلي في الإدارة.
- `config/delivery-zones.json`: وصف إعدادات التوصيل الأولية؛ قاعدة البيانات هي المصدر التشغيلي بعد التأسيس.
